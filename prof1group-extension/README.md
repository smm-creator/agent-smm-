# PROF1Group Агент — Chrome Extension

Розширення для Google Chrome, що автоматизує роботу з сайтом [prof1group.ua](https://prof1group.ua/).

## Можливості

| Функція | Опис |
|---------|------|
| 🆕 Моніторинг новинок | Автоматично перевіряє сайт та надсилає сповіщення про нові товари |
| 🛒 Автозаповнення кошика | Додає товари з розмірами у кошик за вашим списком |
| 📅 Контент-план | Генерує повний місячний план постів українською для соціальних мереж |
| 📊 Google Sheets | Експортує контент-план у Google Таблиці (або CSV) |

---

## Встановлення

### Крок 1 — Завантажити

Папка з розширенням вже готова: `prof1group-extension/`

### Крок 2 — Відкрити Chrome Extensions

1. Відкрий Chrome та перейди до: `chrome://extensions/`
2. Увімкни **"Режим розробника"** (перемикач у правому верхньому куті)

### Крок 3 — Завантажити розширення

1. Натисни **"Завантажити нерозпакований"**
2. Обери папку `prof1group-extension`
3. Розширення з'явиться у списку

### Крок 4 — Закріпити на панелі

1. Натисни іконку пазла 🧩 у Chrome
2. Знайди "PROF1Group Агент"
3. Натисни 📌 щоб закріпити

---

## Використання

### Вкладка "🆕 Новинки"

- Натисни **↺** (кнопка оновлення) у правому верхньому куті popup
- Агент відкриє сайт у фоні, просканує та покаже нові товари
- Сповіщення приходитимуть автоматично (за розкладом із налаштувань)
- Натисни на картку товару — відкриється на сайті

### Вкладка "🛒 Кошик"

Введи список товарів у текстове поле, по одному на рядку:

```
Берці LOWA Z-6S | 43
Куртка 5.11 Tactical Bastion | XL
Рукавички P1G | M
Рюкзак LVC12 21L
```

Формат: `Назва товару | розмір` (розмір необов'язковий)

Натисни **▶ Запустити** — агент перейде до prof1group.ua та додасть товари у кошик.

> ⚠️ Агент НЕ оплачує замовлення — лише заповнює кошик.

### Вкладка "📅 Контент"

1. Обери місяць і рік
2. Обери фокус (загальний / одяг / взуття / спорядження тощо)
3. Натисни **⚡ Згенерувати план**
4. Завантаж як **CSV** або відправ у **Google Sheets**

## Підключення Google Sheets (необов'язково)

> Без цього кроку CSV-завантаження працює одразу.

### Одноразове налаштування (5 хвилин):

1. Відкрий [script.google.com](https://script.google.com) → **Новий проєкт**
2. Видали весь код, встав вміст файлу `appscript.gs` (із папки розширення)
3. Збережи проєкт (Ctrl+S)
4. Натисни **"Розгорнути" → "Новий деплой"**
   - Тип: **Веб-додаток**
   - Виконувати як: **Я**
   - Доступ: **Усі**
5. Авторизуй → скопіюй URL деплою
6. Відкрий налаштування розширення (⚙) → встав URL → Зберегти

Після цього кнопка **"📊 Відкрити Google Sheets"** відкриватиме таблицю з планом.

## Налаштування

Відкрий налаштування через кнопку **⚙** у popup:

| Параметр | Опис |
|----------|------|
| Частота перевірки | Як часто агент перевіряє нові товари (15–360 хв) |
| Сповіщення | Всі нові товари або тільки з міткою "Новинка" |
| Apps Script URL | URL для Google Sheets інтеграції |

## Структура файлів

```
prof1group-extension/
├── manifest.json         — конфігурація розширення
├── background.js         — фоновий агент (моніторинг, алерти)
├── content.js            — скрипт на сайті (кошик, сканування)
├── popup.html/js/css     — інтерфейс popup
├── options.html/js       — сторінка налаштувань
├── utils/
│   ├── content-plan.js   — генератор контент-плану
│   └── sheets.js         — інтеграція з Google Sheets
├── appscript.gs          — Google Apps Script (для Sheets)
└── icons/                — іконки розширення
```

## Часті питання

**Чому агент не знаходить товар у кошику?**
Сайт захищений Cloudflare — потрібно бути авторизованим або відкрити сайт вручну хоча б раз. Після цього агент працює стабільно.

**Чи потрібні API ключі?**
Ні. Розширення використовує ваш браузер і Google акаунт без жодних API ключів.

**Чи безпечно?**
Розширення не передає ваші дані на сторонні сервери. Весь код — відкритий, у папці `prof1group-extension/`.

## Технічні деталі

- Manifest V3 (найновіший стандарт Chrome)
- Cloudflare-стійкий (всі запити через реальний браузер)
- Зберігання даних: `chrome.storage.local` (локально, на вашому комп'ютері)
- Google Sheets: через Google Apps Script (ваш Google акаунт, ваша таблиця)
