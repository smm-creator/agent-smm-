PROF1Group Агент — Налаштування

🔔 Моніторинг новинок

Агент перевірятиме prof1group.ua на нові товари з такою частотою.

📊 Google Sheets інтеграція

Після налаштування Apps Script, вставте сюди URL.

📋 Як підключити Google Sheets (покрокова інструкція)
Відкрий script.google.com і натисни "Новий проєкт"
Видали весь код і встав вміст файлу appscript.gs з папки розширення
Натисни "Розгорнути" → "Новий деплой". Тип: Веб-додаток. Виконувати як: Я. Доступ: Усі
Авторизуй доступ (Google запитає дозвіл). Скопіюй URL деплою
Встав скопійований URL у поле вище і натисни "Зберегти URL"

📝 Notion інтеграція

Отримай на notion.so/my-integrations → «New integration» → скопіюй «Internal Integration Token»

Відкрий свою базу Notion у браузері. URL виглядає як:
notion.so/ВашаРобочаОбласть/DATABASE_ID?v=...
Скопіюй 32-символьний ID (між останнім / і ?)

📋 Як підключити Notion (покрокова інструкція)
Відкрий notion.so/my-integrations → натисни "+ New integration"
Назви інтеграцію PROF1Group Агент, обери свій workspace → "Submit"
Скопіюй "Internal Integration Token" (починається з secret_) → встав у поле вище
Відкрий (або створи) базу даних у Notion, де будуть зберігатися пости. Натисни "···" → "Add connections" → знайди PROF1Group Агент
Скопіюй Database ID з URL та встав у поле вище → "Зберегти"

✅ Агент автоматично створить потрібні колонки (Дата, Тип, Текст, Хештеги, Статус)
