# SMM Стратег — PROF1Group

Веб-інструмент для СММ: генерує **стратегію**, **пропорції типів контенту** і **формати** (карусель, фото, Stories, Reels), плюс щоденний мікс і план на тиждень/місяць.

## Що робить

Як СММ-стратег:

1. Бере бриф (платформа, ціль, фокус товарів, скільки постів на день)
2. Будує щоденний мікс — наприклад **4 пости**:
   - 1 · Фото (фото-пост)
   - 2 · Історія (Stories)
   - 3 · Продаж (карусель)
   - 4 · Гумор (Reels)
3. Рахує **пропорції** типів і форматів
4. Дає стратегію (позиціонування, тон, ритм) + ідеї на тиждень і місяць
5. Експортує план у **CSV/TSV**

Слоти можна змінити вручну в брифі (тип + формат для кожного поста дня).

## Запуск

Відкрий файл у браузері:

```bash
# з кореня репозиторію
open smm-strategy/index.html
# або
npx --yes serve smm-strategy
```

Працює офлайн, без API-ключів.

## Структура

```
smm-strategy/
├── index.html          — інтерфейс
├── styles.css          — стилі
├── app.js              — UI-логіка
└── strategy-engine.js  — движок стратегії / пропорцій / плану
```

## Типи контенту

| Тип | Навіщо |
|-----|--------|
| Фото / візуал | Естетика товару, lifestyle |
| Історія бренду | Behind the scenes, цінності |
| Продаж / акція | Офери, CTA |
| Гумор / мем | Залучення, релотабельність |
| Експертний | Гайди, порівняння |
| UGC / відгук | Соцдоказ |
